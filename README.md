# AL-MOTAMAYEZ

واجهة عربية متجاوبة لإدارة مصنع الملابس. لا تحتاج إلى تثبيت حزم:

1. افتح `login.html` مباشرة في المتصفح.
2. تفتح الصفحة دائمًا على تسجيل الدخول، مع إمكانية الانتقال إلى إنشاء حساب.
3. تبقى الحسابات الجديدة معلّقة إلى أن يحدد الأدمن دور كل حساب ويفعّله.
4. يسجل المستخدم الدخول باسم المستخدم وكلمة المرور، ثم يوجّه تلقائيًا إلى لوحة دوره.

## هيكل المشروع

- `login.html`: تسجيل الدخول وطلبات إنشاء الحساب.
- `dashboards/`: لوحات منفصلة للإدارة والقص والخياطة والعامل والعميل.
- `assets/al-motamayez-logo.png`: شعار AL-MOTAMAYEZ بخلفية شفافة.
- `js/auth.js`: إنشاء الحسابات المعلقة، والتحقق من تسجيل الدخول وتوجيه الدور.
- `js/dashboard.js`: عرض اللوحات وإجراءات الإدارة وتفعيل الحسابات وإدارة الأدمن.
- `css/styles.css`: التنسيق المشترك ودعم الشاشات الصغيرة.

تُحفظ الحسابات في `localStorage` بالمتصفح الحالي، وتُخزّن كلمات المرور باستخدام PBKDF2. لا توجد بيانات اعتماد افتراضية مضمّنة في JavaScript؛ إنشاء حساب أدمن متاح عبر الأجهزة يتطلب تهيئته في خادم آمن وعدم تضمين كلمة مروره في ملفات الواجهة. هذا النموذج المحلي ليس نظام مصادقة آمنًا، ولا يشارك الحسابات بين الأجهزة؛ اربط الواجهة بخادم وقاعدة بيانات وطبّق المصادقة والصلاحيات على الخادم قبل الاستخدام الفعلي. يلزم اتصال محلي آمن يدعم Web Crypto لإنشاء كلمات المرور.
