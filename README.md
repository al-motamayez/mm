# AL-MOTAMAYEZ

واجهة محلية عربية لإدارة مصنع الملابس. لا تحتاج إلى تثبيت حزم:

1. افتح `login.html` في المتصفح.
2. سجّل دخول الأدمن باستخدام اسم المستخدم `ZERO0` وكلمة المرور التي زوّد بها مالك النظام.
3. يسجل المستخدمون الجدد الاسم واسم المستخدم وكلمة المرور. تبقى الحسابات معلّقة حتى يحدد الأدمن الدور ويفعّلها من قسم طلبات الحسابات الجديدة.

## ملفات المشروع

- `login.html`: تسجيل الدخول وإنشاء الحساب.
- `dashboards/`: لوحات الإدارة والقص والخياطة والعامل والعميل.
- `assets/al-motamayez-logo.png`: شعار المصنع بخلفية شفافة.
- `js/auth.js`: إنشاء الحسابات المحلية والتحقق من كلمات المرور والجلسات.
- `js/dashboard.js`: عرض اللوحات وتفعيل طلبات الحسابات وإدارة بيانات المصنع.
- `css/styles.css`: التنسيق ودعم الشاشات الصغيرة.

## حدود النسخة المحلية

الحسابات والطلبات محفوظة في `localStorage` لهذا المتصفح فقط؛ لن تنتقل إلى متصفح أو جهاز آخر. الدخول المحلي مناسب للعرض والتجربة وليس للمعلومات الحساسة، لأن التحقق والصلاحيات داخل المتصفح يمكن تجاوزها. كلمة مرور الأدمن لا تُخزّن كنص صريح في الملفات، لكن لا تستخدم هذه النسخة كحماية حقيقية. مشاركة الحسابات بأمان بين الأجهزة تحتاج خادم مصادقة وقاعدة بيانات.
