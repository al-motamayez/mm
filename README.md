# خيط وإبرة | نظام إدارة مصنع الملابس

نموذج أولي عربي متجاوب لواجهة إدارة مصنع ملابس. لا يحتاج إلى تثبيت حزم:

1. افتح `login.html` مباشرة في المتصفح.
2. اختر نوع الحساب واكتب اسمًا.
3. للتجربة، استخدم `أحمد محمد` أو `مريم علي` لحساب عامل، و`شركة النور` أو `متجر الأمل` لحساب عميل.

## هيكل المشروع

- `login.html`: تسجيل الدخول التجريبي واختيار الدور.
- `dashboards/`: لوحات منفصلة للإدارة والقص والخياطة والعامل والعميل.
- `js/auth.js`: بدء جلسة النموذج التجريبي وتوجيه المستخدم حسب دوره.
- `js/dashboard.js`: بيانات العرض التجريبية، عرض اللوحات، وإجراءات الإدارة.
- `css/styles.css`: التنسيق المشترك ودعم الشاشات الصغيرة.

تُحفظ التعديلات في `localStorage` بالمتصفح الحالي. تسجيل الدخول واختيار الدور هنا للعرض فقط، وليس نظام مصادقة أو تفويض آمنًا؛ لا تستخدمه لبيانات حقيقية. قبل الإنتاج، يلزم ربط الواجهات بخادم وقاعدة بيانات، والتحقق من هوية المستخدم وتطبيق الصلاحيات على الخادم، مع إدارة آمنة للجلسات والبيانات.
