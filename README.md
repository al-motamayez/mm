# AL-MOTAMAYEZ

واجهة عربية متجاوبة لإدارة مصنع الملابس. لا تحتاج إلى تثبيت حزم:

1. افتح `login.html` مباشرة في المتصفح.
2. عند التشغيل الأول، أنشئ حساب الأدمن الرئيسي باسم المستخدم `ZERO0` وحدد كلمة مروره.
3. يستخدم بقية الأشخاص نموذج إنشاء الحساب؛ تبقى حساباتهم معلّقة إلى أن يحدد الأدمن دور كل حساب ويفعّله.
4. يسجل المستخدم الدخول باسم المستخدم وكلمة المرور، ثم يوجّه تلقائيًا إلى لوحة دوره.

## هيكل المشروع

- `login.html`: إعداد الأدمن الأول، وتسجيل الدخول، وطلبات إنشاء الحساب.
- `dashboards/`: لوحات منفصلة للإدارة والقص والخياطة والعامل والعميل.
- `assets/al-motamayez-logo.png`: شعار AL-MOTAMAYEZ بخلفية شفافة.
- `js/auth.js`: إعداد الأدمن الأول، إنشاء الحسابات المعلقة، والتحقق من تسجيل الدخول وتوجيه الدور.
- `js/dashboard.js`: عرض اللوحات وإجراءات الإدارة وتفعيل الحسابات وإدارة الأدمن.
- `css/styles.css`: التنسيق المشترك ودعم الشاشات الصغيرة.

تُحفظ الحسابات في `localStorage` بالمتصفح الحالي، وتُخزّن كلمات المرور باستخدام PBKDF2. هذا نموذج أولي محلي وليس نظام مصادقة آمنًا؛ إدارة الجلسة والصلاحيات وبيانات المتصفح قابلة للتلاعب. لا تستخدم بيانات حقيقية قبل ربط الواجهة بخادم وقاعدة بيانات وتطبيق المصادقة والصلاحيات على الخادم. يلزم اتصال محلي آمن يدعم Web Crypto لإنشاء كلمات المرور.
