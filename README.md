# AL-MOTAMAYEZ

واجهة عربية متجاوبة لإدارة مصنع الملابس. لا تحتاج إلى تثبيت حزم:

1. افتح `login.html` مباشرة في المتصفح.
2. اختر نوع الحساب واكتب اسمًا.
3. أضف حساب المستخدم والبيانات من الواجهة الإدارية.

## هيكل المشروع

- `login.html`: تسجيل الدخول واختيار الدور.
- `dashboards/`: لوحات منفصلة للإدارة والقص والخياطة والعامل والعميل.
- `assets/al-motamayez-logo.png`: شعار AL-MOTAMAYEZ بخلفية شفافة.
- `js/auth.js`: بدء جلسة الواجهة وتوجيه المستخدم حسب دوره.
- `js/dashboard.js`: عرض اللوحات وإجراءات الإدارة.
- `css/styles.css`: التنسيق المشترك ودعم الشاشات الصغيرة.

تُحفظ البيانات في `localStorage` بالمتصفح الحالي. اختيار الدور لا يتحقق من الهوية ولا يوفّر تفويضًا آمنًا؛ لا تستخدم هذه الواجهة لبيانات حقيقية قبل ربطها بخادم وقاعدة بيانات وتطبيق المصادقة والصلاحيات على الخادم.
